# retrospectives/ — история сессий

Короткая запись после каждой рабочей сессии.
Помогает следующему агенту (и тебе) понять что происходило.

## Формат имени
`YYYY-MM-DD.md`

## Структура
```
## Дата: YYYY-MM-DD

### Сделано
- [что реально сделали]

### Решения
- [архитектурные или бизнес-решения, принятые в сессии]

### Осталось
- [что не успели / перенесли]

### Проблемы
- [с чем столкнулись, как решили]
```
